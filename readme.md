# Joel's Dot Files
A repository of configuration files for ZSH, Neovim, and more.

## Required packages

1. `zsh`
2. `stow` (GNU Stow, a symlink farm manager)
3. `ripgrep` (grep alternative, used by Telescope)
4. `starship` (shell prompt, requires nerd fonts)

## Suggested packages

1. `fzf@0.57.0` (fuzzy-finder)
2. `bat@0.24.0` (`cat` alternative)
3. `prettyping@20240117` (`ping` alternative)
4. `neovim@0.10.3` (`vim` alternative)
5. `yt-dlp@2024.12.23` (audio/video downloader)
