# Joel's Dot Files
A repository of configuration files for ZSH, Neovim, and more.

## Required packages

1. `zsh`
2. `stow` (GNU Stow, a symlink farm manager)
3. `ripgrep` (grep alternative, used by Telescope)
4. `starship` (shell prompt, requires nerd fonts)

## Suggested packages

1. `fzf` (fuzzy-finder)
2. `bat` (`cat` alternative)
3. `prettyping` (`ping` alternative)
4. `neovim` (`vim` alternative)
5. `rust`/`cargo`
6. `composer` (PHP package manager)
7. `deno` (JS runtime)
8. `pnpm` (npm alternative)
